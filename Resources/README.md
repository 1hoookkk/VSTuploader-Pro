# VSTuploader Pro Resources

This directory contains resources used by the VSTuploader Pro plugin.

## Files

- `default_thumbnail.jpg` - Default thumbnail image used for YouTube uploads (1280x720px recommended)

## Adding a Default Thumbnail

To add a default thumbnail:
1. Place a JPG image named `default_thumbnail.jpg` in this directory
2. Recommended size: 1280x720px (16:9 aspect ratio)
3. The plugin will use this image when creating videos for YouTube upload

## Future Resources

This directory will also contain:
- Icon assets for the plugin UI
- Template graphics for beat visualizations
- Other media assets needed for YouTube uploads
